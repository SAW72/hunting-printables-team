# Hunting Printables Bot Team

Grok Bot team for creating hunting-themed digital printables, wall art, and decor packs optimized for Etsy.

**Target buyer:** Women decorating homes or buying gifts for husbands, plus female hunters. Focus on rustic, cabin, vintage, pink-camo, and "hunting wife" angles.

## Team Roles

1. **Niche Scout** — Finds trending hunting keywords and sub-niches (deer, duck, turkey, fishing, dogs, "hunting wife" humor).
2. **Designer (Look)** — Design review, competitor comparison, and specific fixes. No Artie.
3. **Copywriter** — Writes Etsy titles, tags, descriptions, and SEO for each listing.
4. **Packager** — Bundles into 5-10 piece sets, creates ZIP-ready folders, and variation forks.
5. **Deployer** — Pushes to GitHub and Cloudflare Pages for live previews.

## Niches to Start

- Hunting wife humor quotes
- Pink camo / "pretty in pink dangerous in camo"

- Cabin gallery wall sets

Price bundles $12–$25. Push 20–30 listings at once.
